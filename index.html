Selected work

  1. 01

    Micro-Exchange on GitHub

    C++23 · Clang · perf · Google Benchmark

    A limit order matching engine. Orders live in a free-list arena and an intrusive list per price level, so insert, cancel and match are O(1) and allocate nothing after startup. Level lookup is O(log n), and creating a level shifts the array.

    Benchmarked 50.5M dispatched operations pinned to one core, timed with lfence and rdtscp minus a measured empty-region cost. The harness had to be fixed first: it counted failed operations as work and timed an error path. Insert costs 100 ns at 512 levels and 7.2 µs at 16,384. Throughput holds 8 to 11M ops/s in cache, 2.3M at 65k live orders.

  2. 02

    itch-parser on GitHub

    Rust · Miri · Clippy pedantic · UDP multicast

    A byte-exact, zero-copy parser for NASDAQ's MoldUDP64 transport and TotalView-ITCH 5.0 feed. All 23 message types are read directly from the borrowed wire buffer. A session state machine detects sequence gaps, stale and duplicate packets, and session rollover.

    I wrote an unsafe pointer version of the hot path and benchmarked both under LTO. The unsafe one was 3–12% slower: alias analysis was worth more than the bounds checks. Kept the safe version, verified with Miri.

  3. 03

    distkv on GitHub

    Rust · Tokio · Raft · Actor model

    The Raft consensus protocol written from scratch as an async actor: tokio::select! over mpsc and oneshot channels, so replicas share no state to lock or deadlock on.

    Implements the safety rules from the paper: election restrictions (§5.4.1), term-validated commit indexing (§5.4.2), randomized election timeouts, and conflict-driven log truncation on leader failover.

  4. 04

    lsm on GitHub

    Rust · crossbeam-epoch · LEB128 · WAL

    A log-structured merge tree: a lock-free skiplist memtable, a write-ahead log with binary record framing, prefix-compressed SSTables, and leveled compaction that merges K runs at a time. Reads take no lock: each one pins a snapshot version, and obsolete tables are unlinked only after the last reader releases it.

    Started as an experiment. The README lists seven hypotheses about where write, read and space amplification come from, and how they move under a factorial sweep of compaction policy, size ratio, filter bits and cache policy.
